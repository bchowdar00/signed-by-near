# Notes on the tables and charts

`out/published/tables.md` and the two charts are written by timestamped code (`publish/rule.py`), so they were not edited after the counted read. These notes say what a reader should know beside them. This file is generated by `publish/check_thesis.py` from the results and the saved rows, and `publish/written.py` checks it; it is not edited by hand.

1. **M8 is shown pooled.** `tables.md`, "M8: program expenditure per request", lines 133 to 135, and chart 2's cost panel. The amounts for June to August 2026 include testnet payouts, and the calls are mainnet calls. On mainnet rows alone NEAR paid 0.0622 NEAR per request in June, 0.0618 in July and 0.0782 in August; the table shows 0.0659, 0.0702 and 0.0820. The other months have no testnet rows. `THESIS.md` §4.4 gives both sets for July to September.
2. **October's M8 row.** `tables.md` line 137. The "0.00" is the amount executed. The 0.1765 beside it is the 76,864.52 NEAR of a proposed report, not yet executed, over October's calls.
3. **The "–" under main.** `tables.md`, "M3 and M4 by month", lines 98 to 110, the five completed months before 2025-11. The dash means no point is printed, not that a window did not finish: for a month with no neardata sample the code prints main as a range with no point. FastAuth had no calls in those months' samples, so main equals narrow: the point is in the narrow column and the interval in the main column.
4. **The resolution audit.** `tables.md` line 13 says "19 transactions read whole, 0 differ". 20 were drawn; one, `6gXczJpg5zbZCDnVa7yPCQ1ruivARq5QQsMoAdXqBNy6`, drew HTTP 429 on 2026-11-11 and was not requested again, so it is not among the 19.
5. **Two months with exactly 100 calls.** May and July 2026 each had 100 `sign` calls in their six 60-second windows (`tables.md` lines 118, 120, 132 and 134). The collector pages newest first and stops at the first page that holds a row older than the window's start; each of these 12 windows ends on such a page, so none was cut short. That stop rule is right only if the pages come newest first, so the order was counted: 182 of the 198 `sign` windows have saved pages (the other 16 were not started before the deadline), 253 pages in all, and 0 pages hold a row newer than the row before it; of the 71 steps from one page to the next, 0 begin with a row newer than the page before ends with.
